# Portafolio de Jesús Magdaleno

Sitio personal enfocado en proyectos de **Python, automatización y visión por computadora**. Presenta el contexto, alcance y tecnologías de los proyectos principales en un formato breve para reclutadores y colaboradores.

## Sitio público

[magdaleno88.github.io/Portafolio](https://magdaleno88.github.io/Portafolio/)

## Proyectos destacados

- SAM AI: retinopatía diabética y clasificación OCT.
- Generador de reportes técnicos en Word.
- Auto-invoice: automatización de carga de facturas.
- SAM Annotate API: backend para flujos de anotación.

## Tecnologías del sitio

HTML semántico, CSS y JavaScript sin framework. El diseño es adaptable, respeta la preferencia de movimiento reducido e incluye navegación por teclado y contenido accesible.

La identidad visual usa mármol blanco con vetas oscuras, tipografía editorial y detalles dorados. La textura está dibujada en SVG dentro del repositorio.

## Ejecutar localmente

Abre `index.html` en un navegador moderno. No requiere instalación ni compilación.
